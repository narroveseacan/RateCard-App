# Button

Tombol aksi dengan tiga varian: primary (cyan, satu per tampilan), secondary (grape), ghost (teks tautan). Tinggi minimal 44px (`md`), huruf Plus Jakarta Sans 800, radius 12px. Fokus: cincin 2px `focus` dengan offset 2px.

- Isi tombol berupa kata kerja ("Simpan", "Lihat sumber").
- `sm` (36px) hanya untuk antarmuka padat di desktop.
- Nonaktif: opacity 0,5 dan tidak bisa diklik; jelaskan alasannya di dekat tombol.
- Ikon bersama teks diberi jarak 8px.
