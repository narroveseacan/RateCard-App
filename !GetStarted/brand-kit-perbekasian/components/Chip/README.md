# Chip

Penanda bab atau lapis, turunan dari chip nomor pada video: lingkaran cyan berisi angka, judul PJS 800, keterangan Spectral Italic berwarna teks sekunder. Radius 20px, border 1px `border`.

- Nomor opsional; tanpa nomor chip menjadi label biasa.
- Untuk status atau tag kecil pakai `radius-pill` dan teks 14px, bukan Chip.
